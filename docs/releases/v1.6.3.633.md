REST Enhanced v1.6.3.633 improves shader-hunting clarity by keeping saved/marked shaders visible even when they are not observed during the latest collection pass.

## Highlights

- Adds an explicit **not seen** state for saved/marked shaders that were not collected during the current hunting scan.
- Keeps collected + marked shaders **yellow**.
- Shows marked-but-not-collected shaders **red** instead of hiding them from the list.
- Reports separate `collected | marked | not seen` counts so saved group state is no longer ambiguous.
- Includes not-seen hashes in the **Marked** filter and shader search.
- Keeps **Unmarked** restricted to collected, unmarked shaders.
- Allows an individual red/not-seen hash to be removed by double-clicking it.
- Adds an explanatory legend and hover tooltip clarifying that a not-seen hash may simply be scene/state dependent rather than invalid.

## Navigation and safety

Not-seen hashes are display-only. They are appended after the collected shader list and do not enter the collected shader set, Prev/Next navigation, Prev/Next marked navigation or preview selection. Existing first-seen navigation order therefore remains unchanged.

This is particularly useful for UI and state-specific shader groups where a saved shader may only execute when a particular menu, HUD element, dialogue state or other game condition is present.

## Validation

The updated shader-hunting UI was runtime-tested successfully with BG3 D3D11 using an existing UI group containing saved hashes absent from the current collection pass. The missing hashes were displayed correctly as red/not-seen entries while collected shader navigation continued to behave normally.

The release workflow builds both x64 and x86, validates PE architecture, version metadata and required add-on exports, and publishes a SHA-256 checksum.

No rendering, preview-resource, Auto Scene Colour, Direct3D or Vulkan execution paths are changed by this release.

## Installation

Extract `release.zip` and place `ReshadeEffectShaderToggler.addon64` (64-bit) or `ReshadeEffectShaderToggler.addon32` (32-bit) beside the game executable used by ReShade. Existing INI configurations remain compatible.

See the included README and changelog for additional setup and usage information.
