# REST Enhanced v1.4.4.633

Corrected hardening release following v1.4.3.633.

## Fixes and hardening

- Excludes the FFXIV constant-copy hook from Win32 builds because its signatures target 64-bit game code.
- Removes the FFXIV copy option from the x86 configuration resolver/UI.
- Treats REST Release compiler warnings as errors on both x86 and x64.
- Narrows the third-party sigmatch C4244 suppression to the include boundary.
- Retains the same shared D3D10/D3D11/D3D12 Automatic Scene Colour path on x86 and x64.
- Preserves the v1.4.3.633 Auto Scene Colour behaviour and BG3 DX11 + DLSS validation baseline.

This release corrects the architecture-hardening gap identified immediately after v1.4.3.633. The Auto Scene Colour rendering path itself was not affected.

Improvements, documentation and testing by **DeViLhoOD**, building on the upstream REST, ShaderToggler and ReShade contributors.
