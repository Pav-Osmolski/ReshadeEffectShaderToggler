REST Enhanced Legacy v1.6.4.580 establishes the permanent ReShade 5.x maintenance line for users who are not moving to ReShade 6.8+ yet.

Release line: `legacy/reshade-5.x`.

## Compatibility

- Targets **ReShade 5.8 through 5.9.2**.
- **ReShade 5.9.2 is recommended** for the Legacy line.
- Compiled against the actual **ReShade 5.8.0 / API 7** headers.
- Versions older than ReShade 5.8 are unsupported.

## Highlights

- Preserves the REST Enhanced v1.6.3 feature set on a dedicated maintenance branch.
- Adapts descriptor tracking and state restoration to API 7's native descriptor-set / descriptor-pool interface.
- Restricts state tracking to shader stages, pipeline stages and dynamic stencil state exposed by API 7.
- Adds an isolated ReShade 5.8 compatibility layer for logging/config helpers and the older Dear ImGui function-table bridge.
- Keeps the modern ReShade 6.8+ / API 20 implementation separate on `main`.
- Isolates Legacy CI and release validation to `legacy/reshade-5.x`.

## Validation

The Legacy branch builds and validates both x64 and x86, including PE architecture, version metadata and required add-on exports.

**Runtime validation completed successfully with ReShade 5.9.2.** The v1.6.4.580 build was tested successfully with no reported regression in the tested REST workflow.

ReShade 5.8.0 is the compile/API baseline, but the runtime validation for this release was performed on ReShade 5.9.2.

## Installation

Extract `release.zip` and place `ReshadeEffectShaderToggler.addon64` (64-bit) or `ReshadeEffectShaderToggler.addon32` (32-bit) beside the game executable used by ReShade.

Users on ReShade 6.8 or newer should use the current REST Enhanced v1.7+ release instead.

Improvements, compatibility work, documentation and testing by **DeViLhoOD**, building on the upstream REST, ShaderToggler and ReShade contributors.
