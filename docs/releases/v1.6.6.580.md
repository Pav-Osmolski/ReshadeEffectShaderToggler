# REST Enhanced v1.6.6.580 — test candidate

This candidate hardens DX12 hunting previews and Vulkan injection. Runtime validation is pending; it is not yet a confirmed in-game fix for issue #15.

- Synchronizes existing preview and group-buffer replacement with known GPU queues.
- Uses explicit DX12 preview-copy transitions and rejects unsupported image topology.
- Caches DX12 copy pipelines by typed destination format, including HDR formats.
- Restores Vulkan pipeline/descriptors after deferred injection without illegal attachment binding; restores legacy descriptor bindings and stage-specific constants.
- Serializes preview payload access, cancels references to reset/destroyed command lists and clears pending techniques on reorder.
- Preserves explicitly set zero-valued dynamic states and clears stale shader matches on null/unknown pipeline binding.
- Shares CI/release binary validation, adds CPU regression and workflow-script checks, and gates tagging on a successful maintained-branch build.
- Documents target limits, actual test coverage, build prerequisites and final-head validation.

Both architecture builds and the GPU regression matrix in docs/RELEASING.md must be recorded before publishing this candidate as stable. Do not equate CI success with game runtime validation.

Improvements and maintenance by DeViLhoOD, building on the upstream contributors credited in README.md.

Legacy maintenance candidate for ReShade 5.8/API 7, with ReShade 5.9.2 recommended. API 20 changes remain isolated to main.

API 7 cannot capture Vulkan dynamic buffer offsets or identify dynamic buffer layouts reliably. This candidate conservatively falls back to ordinary effect placement for ambiguous bound buffer-descriptor layouts; verify the supplied BG3 configuration and diagnostics before stable release.
