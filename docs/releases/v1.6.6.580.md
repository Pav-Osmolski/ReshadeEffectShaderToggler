# REST Enhanced v1.6.6.580 (Legacy / ReShade 5.x)

Maintenance release for ReShade 5.8/API 7; ReShade 5.9.2 is recommended.

- Improves shader-hunting stability when switching previews or replacing render buffers.
- Corrects DX12 preview-copy handling and uses format-specific copy pipelines, including HDR formats.
- Improves Vulkan state restoration after effect injection.
- Hardens preview access, command-list cleanup and shader/technique changes.
- Preserves zero-valued graphics state and clears stale shader matches.
- Consolidates CI, validates both architectures and release metadata, and protects existing release tags/assets.

Legacy Vulkan limitation: API 7 cannot reliably expose dynamic buffer offsets. Ambiguous buffer-descriptor layouts fall back to ordinary end-of-frame effect placement.

Validation: the maintainer reports successful BG3 testing on D3D11 and Vulkan, including functionality and shader hunting, with no crashes observed in that testing. Exact ReShade versions, architectures and per-branch coverage were not separately recorded. Automated x64/x86 builds, regression tests and binary/package checks passed before release preparation and are repeated by the release pipeline.

The Warframe DX12 crash reported in issue #15 has not yet been confirmed resolved in-game. D3D10, Warframe DX12 and HDR-specific runtime checks remain unrecorded for this release.

Improvements and maintenance by DeViLhoOD, building on the upstream contributors credited in README.md.
