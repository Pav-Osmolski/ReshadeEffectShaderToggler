# REST Enhanced v1.6.7.580 (Legacy / ReShade 5.x)

HDR format handling, packaging and build maintenance. For ReShade 5.8/API 7; ReShade 5.9.2 is recommended.

- Prevents previews and copied buffers from confusing FP16 floating-point colour with normalized or integer views of the same storage family.
- Caches each typed view of a game texture separately; improves valid-view fallback and avoids duplicate destruction when HDR linear/sRGB views are identical.
- Keeps effects on the live target when alpha-preserving scratch copies are unavailable on Vulkan/OpenGL. Existing saved preferences are preserved.
- Runs tone-map clamping only when both techniques are ready, and explains that this optional ACES compression is lossy and is not HDR10/PQ or HLG conversion.
- Standardizes historical release-note headings and links the maintainer credit to its GitHub profile.
- Uses one CI/release package manifest, including the changelog, shaders, docs and build provenance.
- Packages the version-controlled BG3 D3D11/Vulkan configurations automatically. SHA256SUMS.txt covers both ZIPs, with an additional configuration checksum/provenance file.
- Downloads pinned dependencies shallowly and in parallel, retaining full main-repository history for validation.

Validation: automated x64/x86 builds, rendering-safety regression tests, 16 packaging/workflow/release regressions, PowerShell/workflow checks and binary metadata validation. The dependency-fetch change reduced the first comparison runs from 39–46 seconds to 24–25 seconds; timings vary by runner and network.

The issue #15 reporter confirmed the preceding release fixed shader-hunting crashes in both official and unofficial ReShade. Their subsequent HDR symptoms were not described in detail. These changes fix concrete format-handling defects; fresh HDR game testing and confirmation of those symptoms remain pending. See [HDR handling and validation](https://github.com/Pav-Osmolski/ReshadeEffectShaderToggler/blob/v1.6.7.580/docs/HDR.md) in the repository (also included as docs/HDR.md in release.zip).

The API 7 Vulkan buffer-descriptor fallback remains unchanged. This maintenance release does not add API 20 colour-space or descriptor capabilities.

Improvements and maintenance by DeViLhoOD, building on the upstream contributors credited in README.md.
