# REST Enhanced v1.4.3.633

Feature and hardening release expanding REST's Automatic Scene Colour support and release validation.

## Highlights

- Adds **D3D10** to the shared Automatic Scene Colour path alongside D3D11 and D3D12.
- Keeps the live-RTV/native-staging path architecture-neutral across **x86 and x64**.
- Promotes x86/x64 parity to a first-class CI and release gate, validating PE architecture, file version metadata and required REST exports.
- Centralises Auto Scene Colour API policy and keeps Vulkan/D3D9 excluded.
- Preserves manual render-target configuration while Auto mode is active and when an unsupported API is encountered.
- Ensures selected techniques still respect ReShade's global enabled state.
- Requires complete live resource views before native staging is used, avoiding partial/invalid copy paths.
- Hardens the release workflow and documents the BG3 DX11 + DLSS regression matrix.

Baldur's Gate 3 in DX11 mode with DLSS remains the primary runtime-validated configuration for the full dynamic-resolution/native-staging path.

Improvements, documentation and testing by **DeViLhoOD**, building on the upstream REST, ShaderToggler and ReShade contributors.
