# REST Enhanced v1.4.0.633

Automatic Scene Colour for D3D12 upscaled rendering, including DLSS/native-staging support, multi-pass technique fixes, diagnostics, documentation and release hardening. Validated in Baldur's Gate 3 with D3D12 + DLSS, including Lumenite_Kernel -> Lumenite_LSAO rendering beneath the UI.

Improvements, documentation and testing by **DeViLhoOD**, building on the upstream REST, ShaderToggler and ReShade contributors.
