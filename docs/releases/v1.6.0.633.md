REST Enhanced v1.6.0.633 adds stable Vulkan Auto Scene Colour and fixes the crash exposed by rapid shader-hunting navigation.

## Highlights

- Vulkan native-resolution image-blit staging keeps selected effects in the scene before later fog and UI composition.
- Injection waits for a proven same-target LOAD pass or a post-pass transition of the exact scene target out of render-target usage. Subpass boundaries are rejected, resource state is restored and recursive injection is guarded.
- Rapid Prev/Next hunting uses owned shader-group snapshots, synchronised shader maps and collected lists, and atomic render-visible state, with no navigation delay added.
- Vulkan hunting safely suppresses selected draws and defers preview copies to legal boundaries. Preview metadata, status messages and RGB/R/G/B controls make target inspection clearer.
- Diagnostics distinguish the current attempt from the last successful injection and report the actual successful Vulkan boundary.

## Validation and compatibility

BG3 Vulkan testing confirmed the Before Fog candidate `0x782733c1` using `2560×1440 → 3840×2160` staging, with no observed flicker and stable rapid shader navigation after the fixes. Shader hashes remain game/configuration dependent.

The release workflow builds both x64 and x86, validates PE architecture, version metadata and required exports, and publishes a SHA-256 checksum. This does not imply in-game validation of every title, architecture or graphics configuration. A fresh DX11, same-resolution Vulkan or x86 runtime test was not performed in this release task.

D3D10/11/12 retain their existing shader-copy staging path. Vulkan requires eligible targets with existing transfer usage; REST skips unsafe boundaries and does not split game render passes. Existing add-on and INI filenames are unchanged.

## Installation

Extract `release.zip` and place `ReshadeEffectShaderToggler.addon64` (64-bit) or `ReshadeEffectShaderToggler.addon32` (32-bit) beside the game executable used by ReShade. Keep your existing INI configuration. See the included README and Automatic Scene Colour guide for setup and limitations.
