# REST Enhanced v1.7.6.680

Configure Vulkan scene transfers directly in REST, with a saved per-game preference and clear restart status.

- Add **Options > Advanced Vulkan options > Enable Vulkan scene transfers (requires restart)**. The setting defaults to off and is saved in the game's REST configuration using **Save changes**.
- Show **Active this launch**, pending changes and launcher-override status. Enabling or disabling the option takes effect after a full game restart; existing Vulkan images are not modified during play.
- Keep `REST_VULKAN_SCENE_TRANSFERS=1/0` as an optional diagnostic override without overwriting the saved preference. Remove it from the launcher to use UI control.
- Preserve all existing FP16 resource eligibility, resource-shim and Vulkan safe-boundary checks.

## Enshrouded setup

Enable the option, save and restart. Keep `RESHADE_DISABLE_GRAPHICS_HOOK=1` and `--keep-vulkan-layers` in the launcher for the tested setup. Resource Shim must be **none**. Select an earlier scene shader, such as `0x46c3d744` in the tested game build, and include the desired effects in the group. In **Ticked techniques are EXCLUDED** mode, untick effects you want injected. Final HUD shaders remain too late for this setup.

See the [saved option guide](../vulkan-scene-transfer-setting.md) and [Enshrouded instructions](../troubleshooting.md#enshrouded-vulkan-testing).

## Validation

The maintainer confirmed successful testing of the new UI setting on both Modern and Legacy builds. Detailed Modern inspection verified saved configuration enabled at startup without a launcher override, FP16 image transfer support, increasing successful renders and sharp menu text over the effected scene after correcting the shader/technique selection. Automated regression tests cover default-off migration, persistence, startup-only activation and override precedence on x64/x86. See the [validation record](../vulkan-ui-setting-validation-20261117.md).

This release changes how the existing optional feature is configured; it does not broaden Vulkan allocation eligibility or claim HDR colour accuracy or a Warframe issue #22 fix.
