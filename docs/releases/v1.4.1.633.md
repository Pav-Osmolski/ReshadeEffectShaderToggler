# REST Enhanced v1.4.1.633

Patch release: restores Auto Scene Colour support for DirectX 11, the renderer used by the validated Baldur's Gate 3 + DLSS configuration. v1.4.0.633 accidentally restricted the feature to D3D12 during release hardening, which disabled the checkbox in BG3 DX11. D3D11 and D3D12 are now supported. Documentation has been corrected accordingly.

Improvements, documentation and testing by **DeViLhoOD**, building on the upstream REST, ShaderToggler and ReShade contributors.
