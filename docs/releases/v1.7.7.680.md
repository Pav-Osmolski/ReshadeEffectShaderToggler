# REST Enhanced v1.7.7.680

Bind a controller button or D-pad direction to a REST toggle group. The binding works alongside the group's keyboard shortcut and toggles the group once per press while the game has focus.

1. Open ReShade → **Add-ons** → **REST Enhanced** and edit a toggle group.
2. Choose **Bind controller button**, select the device and press the desired control.
3. Select **Save changes** to keep the binding. Use **Clear controller** to remove it.

REST reads buttons through Windows DirectInput in non-exclusive mode. Native controllers and DS4Windows virtual outputs can be selected when Windows exposes them as DirectInput game controllers. Bindings are stored for the selected Windows device instance. USB/Bluetooth changes or virtual controller recreation may require rebinding. Available buttons depend on the driver, including Edge paddles and Xbox Share. The binding UI supports buttons and the D-pad. See the [controller binding guide](https://pav-osmolski.github.io/ReshadeEffectShaderToggler/docs/groups-and-configuration/#bind-a-controller-button).

The maintainer confirmed the feature works in the Modern test build. Automated checks cover x86/x64 and binding persistence. Separate live-game coverage for DualSense Edge, Xbox controllers and DS4Windows virtual outputs has not been recorded.

The documentation site also includes Google Search Console verification. The Dark Souls Remastered crash investigation remains open.
