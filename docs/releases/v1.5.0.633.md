# REST Enhanced v1.5.0.633

Major quality-of-life release introducing the **REST Enhanced — ReShade Effect Shader Toggler** identity while preserving the established repository, binary and INI filenames for compatibility.

## Highlights

- Adds deterministic **Saved / Unsaved changes** tracking and a clearer **Save changes** workflow.
- Adds safe **Clone** and confirmed **Delete** group actions.
- Adds compact PS / VS / CS / FX group summaries and Auto Scene Colour status.
- Adds shader-hash search plus **All / Marked / Unmarked** filtering.
- Adds mouse controls for previous/next/marked shader navigation and mark/unmark.
- Adds **Recollect** across pixel, vertex and compute shader stages while retaining marked hashes.
- Restores functional configurable shader-hunting and group toggle hotkeys with exact Ctrl/Shift/Alt matching.
- Adds optional compute-shader hunting bindings.
- Adds shortcut-conflict warnings.
- Hides inherited Invocation/Descriptor keybinding controls that have no execution path while preserving their saved INI values.
- Widens the default shader-hunting pane for complete hash visibility while retaining the adjustable splitter.
- Hardens marked-shader navigation when no shader is currently selected.
- Improves Auto Scene Colour status with clearer injection/native-staging reporting and **Copy diagnostics**.
- Persists overlay opacity and shader-collection frame count.
- Uses game-agnostic Graphics API labels (D3D10, D3D11, D3D12) while retaining BG3 DX11 + DLSS as the documented primary regression reference.
- Keeps the D3D10/D3D11/D3D12 Auto Scene Colour rendering architecture unchanged from the validated v1.4 path.

Improvements, documentation and testing by **DeViLhoOD**, building on the upstream REST, ShaderToggler and ReShade contributors.
