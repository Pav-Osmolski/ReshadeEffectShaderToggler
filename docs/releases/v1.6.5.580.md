REST Enhanced Legacy v1.6.5.580 backports the per-group **Hide marked shaders** feature to the ReShade 5.x maintenance line.

## Hide marked shaders

Groups now include a **Hide marked shaders** option. When enabled on an active group, REST suppresses graphics draws matching that group's marked pixel or vertex shaders.

This allows an existing `UI` group to act as a configurable HUD toggle for screenshots and photo-mode style use. Mark the relevant UI shaders, enable **Hide marked shaders**, and use the group's normal hotkey to hide or restore the HUD.

The feature can also be used temporarily on other groups to see exactly what their marked shaders contribute.

### Safety and behaviour

- Supports normal, indexed and typed indirect graphics draws.
- Preserves suppression across repeated draws that reuse the same bound pipeline.
- Clears queued REST effect, binding, constant and preview work for skipped calls.
- Compute dispatches are deliberately not suppressed.
- Existing configurations remain unchanged because the new option defaults to off.
- Persists through INI save/load, group cloning, Copy group / Import group and dirty-state tracking.

## Legacy compatibility

This release remains compiled against **ReShade 5.8.0 / API 7** and targets **ReShade 5.8 through 5.9.2**, with ReShade 5.9.2 recommended.

No ReShade 6.8/API 20 compatibility layer or Modern-only code is introduced.

## Validation

Runtime testing confirmed the feature works correctly with **ReShade 5.9.2**, including repeated HUD draws and normal group-hotkey toggling.

Both x64 and x86 builds pass architecture, version metadata and required add-on export validation.
