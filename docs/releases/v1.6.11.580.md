# REST Enhanced v1.6.11.580 (ReShade 5.x)

Bind a controller button or D-pad direction to a REST toggle group with ReShade 5.8–5.9.2 full add-on support. ReShade 5.9.2 is recommended.

In the REST group editor, select **Bind controller button**, choose the device, and press the control. Use **Save changes** to keep the binding or **Clear controller** to remove it. A keyboard shortcut can still be used for the same group. Controller bindings work while the game has focus and are saved for the selected Windows device instance.

REST reads controllers in non-exclusive mode through Windows DirectInput. Choose the native device or a DS4Windows virtual output exposed by Windows. The buttons available depend on the device, connection and driver. This release binds digital buttons and the D-pad. See the [controller binding guide](https://pav-osmolski.github.io/ReshadeEffectShaderToggler/docs/groups-and-configuration/#bind-a-controller-button).

This backport uses the Legacy ReShade SDK. The maintainer verified the feature in the Modern test build. Legacy validation consists of the x86/x64 builds and automated checks, including binding persistence. Separate Legacy in-game checks and controller-specific coverage for Edge, Xbox and virtual outputs have not been recorded.
