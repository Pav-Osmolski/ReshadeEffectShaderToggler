REST Enhanced v1.6.2.633 is a focused stability release for Direct3D shader hunting, with a quieter and more deliberate GitHub Actions workflow.

## Highlights

- Fixes a reproducible D3D11 crash-to-desktop when holding **Prev** or rapidly navigating shaders during shader hunting.
- Restores the correct Direct3D preview-resource model: the backing preview texture may remain typeless, while SRV/RTV views use a compatible typed format.
- Prevents preview compatibility checks from querying a missing SRV after view creation fails, turning that failure into a safe unavailable-preview state instead of a possible backend crash.
- Keeps the Vulkan typed preview-image path and safe deferred-preview behaviour unchanged.
- Tightens GitHub Actions so open PRs no longer spawn a redundant build for every WIP commit; explicit test builds remain available through manual dispatch.
- Removes the obsolete Vulkan branch-specific per-push test workflow.

## D3D preview stability

The recent Vulkan preview work exposed a regression in the shared Direct3D preview allocation path. Direct3D preview resources are intentionally created with a typeless format, but their resource views must use a compatible typed format. The affected code attempted to create the SRV using the typeless resource format, which caused view creation to fail on D3D11.

Rapid shader navigation could then reach the next compatibility check with a valid preview resource but a null preview SRV. REST now validates the SRV handle before asking ReShade for its description and uses the correct typed source-view format for Direct3D SRV/RTV creation.

The correction applies to the shared D3D10, D3D11 and D3D12 preview path. The crash fix was reproduced and runtime-tested successfully with BG3 on D3D11. D3D10 and D3D12 use the same corrected code path but were not separately game-tested for this release.

## CI and release hygiene

- Automatic PR validation now runs when a PR is opened, reopened or marked ready for review rather than for every synchronize/WIP push.
- Build-affecting changes merged to `main` still receive the normal x86/x64 validation.
- `workflow_dispatch` remains available for explicit WIP/test binaries.
- The obsolete `Vulkan Test Build` workflow was removed after Vulkan support was merged and stabilised.

## Validation and compatibility

BG3 D3D11 was used to reproduce the held-Prev CTD and to confirm the corrected preview path no longer crashes under sustained shader navigation.

The release workflow builds both x64 and x86, validates PE architecture, version metadata and required add-on exports, and publishes a SHA-256 checksum. This does not imply in-game validation of every title, architecture or graphics configuration.

Vulkan retains the safe-boundary preview capture, typed preview images, image-blit staging and resource-state restoration introduced and hardened in v1.6.0.633/v1.6.1.633.

## Installation

Extract `release.zip` and place `ReshadeEffectShaderToggler.addon64` (64-bit) or `ReshadeEffectShaderToggler.addon32` (32-bit) beside the game executable used by ReShade. Existing INI configurations remain compatible.

See the included README, changelog and Automatic Scene Colour documentation for setup and limitations.
