REST Enhanced v1.7.0.680 establishes the modern ReShade 6.8+ compatibility line and updates REST to the ReShade 6.8.0 / API 20 add-on interface.

## Highlights

- Pins the ReShade dependency to the exact **ReShade 6.8.0 / API 20** baseline.
- Updates REST's add-on callbacks and metadata exports for the current ReShade API.
- Updates swapchain callback signatures for the current API.
- Updates render-pass callbacks to the API 20 signatures and consumes the new Vulkan render-pass **suspend/resume** flags.
- Keeps REST's conservative Vulkan subpass safeguards in place for traditional render-pass transitions where a false boundary would be unsafe.
- Preserves the established D3D11/D3D10/D3D12 behavior while modernizing the shared API layer.
- Defines ReShade 6.8+ as the active development line. ReShade 5.x users are supported separately by **REST Enhanced Legacy** on `legacy/reshade-5.x`.

## Validation

The modernization branch builds and validates both x64 and x86, including PE architecture, version metadata and required add-on exports.

**Runtime validation completed successfully with ReShade 6.8.0.** Baldur's Gate 3 was tested with the v1.7.0.680 build and no regression was observed in the tested REST workflow.

The ReShade 5.x compatibility line was also separated and validated independently, so API-7 compatibility code does not leak into the modern API-20 implementation.

## Installation

Extract `release.zip` and place `ReshadeEffectShaderToggler.addon64` (64-bit) or `ReshadeEffectShaderToggler.addon32` (32-bit) beside the game executable used by ReShade.

This release requires **ReShade 6.8 or newer**. Users remaining on ReShade 5.8-5.9.2 should use the REST Enhanced Legacy release instead.
