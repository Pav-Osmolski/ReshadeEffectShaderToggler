# Game guides

These guides describe known working configurations and their limits. Game updates, renderers and graphics settings can change hashes and target eligibility.

| Game | What is covered |
|---|---|
| [Enshrouded](games/enshrouded.md) | Vulkan launch requirements, saved scene transfers and the earlier scene boundary for sharp UI |
| [Baldur's Gate 3](games/baldurs-gate-3.md) | Separate D3D11/Vulkan configs, DLSS staging and choosing an injection group |

For another game, follow [shader hunting](shader-hunting.md) and [effect placement](effect-placement.md). Use a separate group for [HUD hiding](ui-control.md).

The [validation archive](validation.md) records additional RE4/D3D9 checks and the scope of each release. It is a test record, not a collection of universal game presets.
